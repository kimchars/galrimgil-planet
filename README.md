# 갈림길 행성

진로 갈림길을 AI 배심원과 함께 미리 살아보는 게임이에요.

지금 갈 수 있는 길을 보고, 그 길을 아는 배심원들(인사담당자, 현직자, 선배, 부모님 등)의 의견을 듣고, 고른 길을 미리 살아봐요. 모든 선택은 체크포인트 행성에 핀으로 남아서 언제든 되돌아가 다른 길을 시도할 수 있어요.

## 실행 방법

빌드가 필요 없는 HTML 파일 하나예요.

- `index.html`을 브라우저로 열면 바로 실행돼요.
- 또는 이 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속

외부 의존성은 Google Fonts와 Three.js(cdnjs) 두 개뿐이고, Three.js를 못 불러오면 체크포인트 행성이 2D 나무로 대신 그려져요.

## 게임 흐름

1. **출발점 고르기**: 직군(IT·개발, 디자인·콘텐츠, 금융·경영, 공공·행정), 종착지, 지금 상태, 모아둔 돈, 보유 자격증
2. **갈림길 보기**: 자격증 / 프로젝트 / 대회 / 지원 중 다음 길 후보와 성공률, 기간, 비용
3. **배심원 듣기**: 배심원 4명이 1라운드 의견, 2라운드 반박, 판결
4. **미리 살아보기**: 고른 길을 몇 개월 진행하고 스탯 탑과 자금이 변해요
5. 종착지에 합격하거나 72개월이 지나면 회고와 평행 경로 비교

## 코드 구조 (`index.html` 안의 `<script>`)

| 구역 | 내용 |
| --- | --- |
| 1. 규칙표 | 스탯, 직군별 종착지와 노드(`FAM`), 이벤트, 질문 |
| 2. 배심원 | 배심원별 가중치와 말투(`JU`), 갈림길 종류별 배심원 구성 |
| 3. 상태 | 체크포인트 트리(`tree`), 성공 확률 계산(`probOf`) |
| 4. AI 자리 | `aiFork()`, `aiJury()` — 지금은 규칙 기반 |
| 5~6. 화면 | 설정, 갈림길 지도, 배심원, 결과, 엔딩 |
| 7. 픽셀 무대 | 캐릭터 애니메이션 (canvas) |
| 8. 체크포인트 행성 | Three.js 지구본, 실패 시 2D SVG 나무 |

## 다음 작업 아이디어

- `aiFork()`, `aiJury()`를 LLM 호출로 바꾸고, 실패하거나 느리면 지금의 규칙 응답으로 돌아오게 두기 (시연이 끊기지 않도록)
- 성공 확률과 스탯 변화는 계속 규칙표로만 계산하기
- 직군과 노드 데이터 보강

## 참고

배심원 의견과 갈림길 추천은 현재 규칙 기반 응답이에요. 자격증과 채용 절차 설명은 일반적인 내용이라 실제 일정과 요건은 공식 공고로 확인해야 해요.
